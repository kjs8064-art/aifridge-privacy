방법 1. 앱에서 직접 삭제(권장)

앱 실행 → 더보기 → 설정 → 위험 구역 → 계정 삭제 → 확인

확인을 누르면 계정과 개인 데이터 삭제가 시작되며 되돌릴 수 없습니다. 이 기기의 데이터는 즉시 지워지고, 서버 쪽 반영에는 시간이 걸릴 수 있습니다.

방법 2. 이메일로 삭제 요청

앱에 접근할 수 없으면 가입에 사용한 Google 계정 이메일로 계정 삭제 요청을 보내 주세요.

가입 이메일과 요청 이메일의 일치 여부로 본인 확인을 진행하며, 계정 정보는 제3자에게 제공하지 않습니다.

처리 기간

  • 앱에서 직접 삭제: 확인 즉시 처리가 시작됩니다. 이 기기 데이터는 바로 삭제되며, 서버 데이터 정리는 보통 몇 분 내에 끝납니다. 실패한 정리 단계는 자동 재시도될 수 있습니다.
  • 이메일 요청: 본인 확인 후 요청일로부터 최대 30일 이내에 삭제를 완료합니다.

삭제되는 데이터

  • Google 로그인 프로필(이메일·이름·고유 ID), 멤버십과 알림 토큰
  • 개인 재고, 소비·폐기 이력, 앱이 만든 사진 캐시, 계정 관련 로컬 설정
  • 앱이 저장한 광고 제거·구매 권한 상태

공유 그룹 데이터와 보존 항목

다른 멤버가 남아 있는 공유 그룹의 공동 재고·이력·이미지는 남은 멤버가 계속 사용할 수 있도록 유지될 수 있습니다. 탈퇴 시 내 멤버십은 삭제되고, 내가 소유자였다면 남은 멤버에게 소유권이 이전됩니다. 내가 마지막 멤버였다면 그 그룹과 하위 데이터는 삭제 대상입니다.

  • Google Play의 결제 기록은 Google Play가 보관·관리합니다. 앱은 카드번호 등 결제수단 정보를 저장하지 않습니다.
  • Firebase Crashlytics의 익명 진단 로그는 수집 후 90일이 지나면 자동 삭제됩니다.
  • 법령상 보관 의무가 있는 기록이 있으면 해당 법정 기간 동안만 보관한 후 파기합니다.
