AI냉장고 - 찍고관리 (앱 내 표기: SnapStock · 찰칵재고)

시행일: 2026년 6월 7일 · 최종 개정일: 2026년 8월 17일

AI냉장고 - 찍고관리(이하 "앱")는 식재료 재고를 관리하는 서비스입니다. 본 방침은 앱이 수집·이용·보관하는 정보와 이용자의 권리를 설명합니다.

1. 수집하는 정보

1-1. 로그인과 서비스 이용

  • Google 계정 인증 정보: 이메일 주소, 표시 이름, 프로필 사진 URL(Firebase Authentication 로그인 시)
  • 재고 및 이용자가 입력한 내용: 식재료 이름, 수량, 소비기한, 카테고리, 메모, 재고·소비·폐기 이력
  • 품목 이미지: 이용자가 촬영하거나 선택해 첨부한 원본은 그대로 저장하지 않고, 긴 변 최대 150px JPEG 썸네일로 변환하여 Cloud Firestore에 저장합니다. 이 썸네일은 기기 간 동기화와 공유 그룹 멤버 간 표시를 위해 사용됩니다.
  • OCR/AI 스캔 이미지: 이용자가 영수증·제품 포장 스캔을 실행하면, 식재료 정보 추출을 위해 이미지가 Google Gemini API로 전송되어 분석됩니다. 이용자가 스캔 결과를 저장하면 해당 이미지는 품목 이미지로 저장될 수 있으며, 이 경우 위와 같은 썸네일 보관 기준이 적용됩니다.

1-2. 자동 수집·처리 정보

  • 충돌 및 오류 정보: 기기 모델, OS·앱 버전, 충돌 로그(Firebase Crashlytics)
  • 푸시 알림 정보: 푸시 토큰, 사용자 ID, 기기 모델, 타임스탬프(Firebase Cloud Messaging)
  • 광고 관련 정보: Google Mobile Ads(AdMob)는 광고 제공, 분석과 사기 방지를 위해 IP 주소(대략적인 위치 추정), 앱·제품 상호작용, 진단 정보, Android 광고 ID·앱 세트 ID를 자동으로 처리할 수 있습니다. 앱은 정밀한 기기 위치를 수집하지 않습니다.
  • 광고 제거 구매 정보: 광고 제거 일회성 구매의 구매 토큰과 구매 날짜를 권한 검증·복원에 사용합니다. 앱은 카드번호 등 결제수단 정보를 직접 수집하지 않습니다.

2. 이용 목적

  • 로그인, 재고 등록·수정·삭제, 기기 간 동기화와 공유 그룹 기능 제공
  • 품목 이미지 표시, OCR/AI 분석, 소비기한 알림과 푸시 알림 제공
  • 오류 분석과 앱 안정성 개선
  • 광고 제공·분석·사기 방지 및 광고 제거 구매 권한의 검증·복원

3. 보관 및 삭제

  • 재고 데이터와 품목 이미지 썸네일은 Cloud Firestore에 저장되며, 이용자가 해당 품목 또는 계정을 삭제할 때까지 보관됩니다.
  • 계정을 삭제하면 이용자의 프로필, 개인 품목, 멤버십과 마지막 멤버인 공유 그룹의 하위 데이터는 삭제 대상입니다.
  • 다른 멤버가 남아 있는 공유 그룹의 품목·이력·이미지 썸네일은 남은 멤버의 서비스 이용을 위해 유지될 수 있으며, 소유권은 남은 멤버에게 이전될 수 있습니다.
  • Crashlytics 충돌 로그는 수집 후 90일간 보관된 뒤 자동 삭제됩니다. 이메일 삭제 요청은 본인 확인 후 최대 30일 이내 처리합니다.
  • Gemini API로 전송된 이미지의 처리·보관에는 Google의 약관 및 개인정보처리방침이 적용됩니다.

4. 제3자 서비스 및 제공

앱은 개인정보를 판매하지 않습니다. 다음 서비스 제공에 필요한 범위에서 정보를 전송·처리하며, 각 제공자의 처리에는 해당 제공자의 약관과 개인정보처리방침이 적용됩니다.

  • Firebase Authentication (Google LLC): 사용자 인증
  • Cloud Firestore (Google LLC): 재고·그룹 데이터와 이미지 썸네일의 저장·동기화
  • Firebase Crashlytics (Google LLC): 충돌 분석
  • Firebase Cloud Messaging (Google LLC): 푸시 알림 전송과 토큰 관리
  • Google Play Billing (Google LLC): 광고 제거 일회성 구매의 처리·권한 검증·복원
  • Google Mobile Ads(AdMob) (Google LLC): 광고 제공, 분석, 사기 방지. 위 1-2의 광고 관련 기술 정보를 자동으로 처리·공유할 수 있습니다.
  • Google Gemini API (Google LLC): 이용자가 실행한 영수증·포장 이미지 OCR/AI 분석

OCR/AI 스캔은 선택 기능입니다. 무료 Gemini API 등급이 적용되는 경우 전송된 콘텐츠와 응답이 Google 제품·서비스 및 머신러닝 기술의 제공·개선·개발에 사용되거나 품질 향상을 위해 검토될 수 있습니다. 영수증·포장 이미지에 민감한 정보가 포함될 수 있다면 해당 부분이 촬영되지 않도록 하거나 OCR 스캔을 사용하지 마십시오.

5. 이용자의 권리와 삭제 요청

이용자는 앱에서 재고를 직접 삭제하거나, 계정 및 데이터의 열람·수정·삭제를 요청할 수 있습니다.

계정 및 데이터 삭제 안내

앱 내 경로와 이메일 요청 방법, 삭제·보존 항목과 처리 기간은 계정 및 데이터 삭제 안내 페이지에서 확인할 수 있습니다.

6. 카메라와 사진 권한

카메라·사진 접근은 바코드·OCR 스캔 또는 품목 사진 첨부를 위해 요청됩니다. 두 기능 모두 이용자가 직접 실행하는 선택 기능입니다.

7. 이용 연령

앱은 만 18세 이상을 대상으로 합니다. 앱은 만 18세 미만 이용자의 정보를 의도적으로 수집하지 않으며, 그러한 사실을 알게 되면 해당 정보를 삭제합니다.
